## 📌 Описание
Этот репозиторий содержит **Code Style Guide (CSG)** — стандарт оформления кода для проектов.
Это целевой стандарт для всех **новых** проектов FelineFantasy;
существующие приводятся в соответствие постепенно.

## 📖 Содержание
- [CSG (English)](./CSG.md)
- [CSG (Русский)](./CSG.ru.md)

## 🔄 Использование
Все **новые** проекты FelineFantasy следуют этому стандарту.

Существующие проекты приводятся в соответствие постепенно.
Каждый проект указывает свой уровень соответствия в собственном README:

- `CSG: full` — полностью соответствует
- `CSG: partial` — частично соответствует, миграция в процессе
- `CSG: legacy` — не соответствует, оставлен как есть

Если вы хотите внести вклад, пожалуйста, соблюдайте эти правила.
